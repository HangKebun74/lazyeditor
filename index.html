LAZYEDITOR v1.0.0

Lightweight WYSIWYG HTML Editor - No Dependencies, ASCII Interface

🚀 Quick Start

Just 2 Steps!

  1. Include both CSS and JS files in your HTML:
    <link rel="stylesheet" href="lazyeditor.css">
    <script src="lazyeditor.js"></script>
  2. Add class to any textarea:
    <textarea class="lazy[m]">Your text here</textarea>

📋 Available Presets

Preset Buttons Description
lazy[zzz] None Empty toolbar (just view toggle)
lazy[xs] B, I Bold, Italic
lazy[s] B, I, * Adds bullet list
lazy[m] B, I, *, 1., URL DEFAULT: Adds numbered list and link
lazy[l] B, I, U, *, 1., URL, --- Adds underline and horizontal line
lazy[xl] B, I, U, S, *, 1., URL, --- Adds strikethrough
lazy[xxl] All except IMG and TABLE Full featured with code, quote, print, RTL

⚙️ Configuration

Edit these settings in lazyeditor.js:

const LE_CONFIG = {
    debugMode: true,                    // Show/hide debug panel
    defaultHeight: '160px',             // Initial editor height
    defaultPreset: 'm',                 // Default button preset
    enablePlaceholder: true,            // Show placeholder text
    showBranding: true,                 // Show "LazyEditor" in status bar
    debounceDelay: 250                  // Auto-save delay (ms)
};
